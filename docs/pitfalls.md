# 边界与排查

- 保存成功但地图不变：先查询会话，再确认响应规则、MITM、证书与实际请求是否匹配；最后在目标应用重新定位。前端坐标与保存提示不能证明响应已修改或系统已采纳。
- 到期仍显示目标：600 秒控制响应改写资格，不是 GPS 立即复位定时器。系统和应用缓存、GPS 信号、请求时机都可能影响结果；手动刷新设置也不是即时恢复保证。
- 新手机控制页报 unavailable：旧 loader 缓存为空。使用默认完整独立脚本，或按 README 执行一次缓存引导。
- 没有高清或双指能力：无自备高德配置时回退栅格；配置有误、网络受阻、服务配额耗尽也可能导致矢量地图不可用。
- 清除后仍有收藏：收藏位于 Safari 本地存储，清除会话不会删除它；清除网站数据会影响收藏和参考位置。
- 模板无响应脚本：上游解析器因许可不明确而未公开。缺少该私有构建产物时只能测试控制层。
- 快捷指令停在设置：符合设计。快捷指令不替用户操作系统定位开关；“无”动作避免把返回值继续交给 Safari，不构成后台自动化保证。

自包含测试证明模拟运行时中的控制、存储、转换与期限行为。可选二进制测试仅证明合成响应的改写边界。两者都不能替代真实设备、不同网络与系统版本上的端到端验收。

原使用场景已有用户确认的 Wi-Fi/蜂窝反馈；没有据此推导通用兼容性。Mac 完全关闭后的完整链路及本公开包在干净手机上的安装尚未独立验证。
