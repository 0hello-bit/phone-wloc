# 架构与数据边界

`settings.js` 负责本地 HTTP 控制接口与页面渲染；`session.js` 在控制页与响应包装层间共享严格会话校验。`page.html` / `page.css` 构成界面，`map.js` 提供栅格选点与 WGS-84 / GCJ-02 转换，`amap.js` 是用户自行配置的高德 JS SDK 适配层，`places.js` 管理 Safari 本地记录，`experience.js` 管理保存、清除及快捷指令入口。

Shadowrocket 持久化键 `wloc_settings` 保存纬度、经度、精度与会话时间；每次保存将截止时间设为开始时间加 600000 毫秒。会话必须坐标有效、起止时间有效、时长恰为 600 秒且当前时间处于有效区间。无效或过期时即使清理存储失败，也返回无会话。此约束依赖设备时钟，不是防篡改的授权凭据。

`response-wrapper.js` 先校验会话，无会话直接 `$done({})` 透传；有效时才运行私有构建中注入的上游解析器。本仓库不含该解析器。包装层只在匹配网络响应到达时执行，不能驱动系统产生新的定位请求。

`phone-wloc-amap.js` 仅加载手机持久化中的控制脚本；全新安装默认改用独立构建的 `phone-wloc-settings.js`，避免空缓存依赖。构建脚本另可生成一次性 loader 引导脚本。

地图选点传入会话的坐标使用 WGS-84；高德底图与坐标转换属于界面层。收藏、最近地点及进入时参考位置放在 Safari 的 `phone-wloc-places-v1` 本地存储，与 Shadowrocket 会话不同步清理。进入时记录是系统返回的参考值，可能受缓存或既有虚拟目标影响。

构建目录 `dist/` 不含上游代码；`.private-build/` 专用于用户自备上游、地图配置及衍生产物。两者均被 Git 忽略，发布应从显式源码清单生成，不能打包整个工作目录。
